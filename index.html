วิธีตั้งค่ารถเช่า

  1. ที่ Admin → ทะเบียนรถ เพิ่มทะเบียนใหม่ หรือเปลี่ยนคอลัมน์ "ประเภท" ของทะเบียนเดิมเป็น "รถเช่า" (ทะเบียนเดิมถูกตั้งเป็น "รถบริษัท" ไว้ก่อน)
  2. ที่ จัดการบัญชีผู้ใช้งาน สร้างบัญชีและเลือกสิทธิ์ "พนักงานขับรถ" / "รถเช่า" / "Admin"
  3. ใบงานของรถเช่าจะปรากฏในเมนู "รถเช่า" หลังกด "บันทึกใบงาน"
  4. บัญชี User เดิมจะกลายเป็นสิทธิ์ "พนักงานขับรถ" อัตโนมัติ
